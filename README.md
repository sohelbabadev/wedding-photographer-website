# RIVAYAT — Indian Wedding Photography

Professional black-and-white themed website for an Indian wedding photography studio (Mumbai-based).

## Pages

- Home, About, Our Team, Our Work, Packages, Contact

## Stack

Next.js · TypeScript · Tailwind CSS · Framer Motion

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
